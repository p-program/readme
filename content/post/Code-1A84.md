最近、『攻殻機動隊 SAC_2045』のシーズン2を再び観終わりましたが、キャラクターが3D化されたことで表情や動きが以前ほど繊細でなくなったと明らかに感じました。また、江崎プリン以外の新キャラクターにはあまり印象に残るところがありませんでした。

## 江崎プリン

江崎プリンというキャラクターの神話的原型は「テセウスの船」（Ship of Theseus）です。
物語の後半では、すでにNに進化した島村孝が一人で人類陣営全体と対抗します。

![image](/image/post/Code-1A84/1A84.jpg)

そして、「Double-though」ウイルス（身体と意識が分離するウイルス）の影響を受けないのは主人公と江崎プリンだけです。

```go
package main

import (
	"fmt"
	"time"
)

type Information struct {
	content string
}

func Actor(core string, inbox <-chan Information) {
	for msg := range inbox {
		fmt.Printf("Actor %s received: %s\n", core, msg.content)
	}
}

func main() {
	memory := make(chan Information)
	go Actor("1A84", memory)
	memory <- Information{content: "立ち上がれ、江崎プリン！"}
	time.Sleep(time.Second)
}
```

明らかに、作者のテセウスの船に対する答えは「はい」です。
厳密に言えば、再起動した江崎プリンは`Code. 1A84`をコアとして、記憶のバックアップから起動したポストヒューマンと呼ぶべきでしょう。

ゴーストはなくても、彼女は元の人間性を保ち続けています。

偶然にも、東西の神話において、テセウスの船の問題に対する答えはどちらも「はい」です。

## 哪吒（ナタ）

哪吒は『封神演義』の中で、龍王の三太子を殺したために大きな災いを招きました。両親や陳塘関の民を巻き込まないように、「骨を削り父に還し、肉を削り母に還す」として自ら命を絶ちました。
彼の魂は太乙真人の助けを得て母に夢で託され、翠屏山に行宮を建てて香火を受け、金身の再生を願いました。

![image](/image/post/Code-1A84/13z.jpg)

しかし父の李靖が行宮を破壊し、哪吒の再生の道を断ち切りました。最終的に太乙真人は蓮の根を骨格に、蓮の葉を筋肉にして哪吒の蓮根化身を再生し、彼を蘇らせました。

## プロメテウス

タイタン神プロメテウスは火を盗んだ罰としてゼウスにより高加索山に鎖で繋がれ、毎日鷲に肝臓を啄まれ、夜には再生するという苦しみを繰り返しました。

![image](/image/post/Code-1A84/Προμηθεύς.jpg)

一方、善良なケンタウロスのカイロンはヘラクレスの毒矢に誤って射られ、激しい痛みに苦しみましたが、不死身のため死ぬこともできませんでした。
プロメテウスを救うため、そしてカイロンの解放のために、彼らは協定を結びました。カイロンは自らの不死を放棄し、プロメテウスの罰を代わりに受けて冥府に入り、プロメテウスは自由を得ました。

**爾曹身與心俱滅 不廢江河萬古流**
